# Release review

1. Identify the document or change set the user wants reviewed. Ask if it is unclear.
2. Read [the checklist](references/checklist.md) and the relevant workspace evidence. Do not assume an unchecked item is complete.
3. Return three sections: **Ready**, **Needs attention**, and **Not verified**. Put release blockers first and cite paths for findings.
4. Do not edit the report or publish it unless the user asks.
